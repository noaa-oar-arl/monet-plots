    Observation, model and bias maps¶

    compare_spatial creates three columns: observations, model values, and model minus observations. Observations and model values share one scale; bias uses a separate diverging scale centered on zero. Add row="model" or row="season" for repeated comparisons.

    import cartopy.crs as ccrs
import monet_plots as mp

# DataArrays already collocated on the same grid, in the same physical units.
# observations: lat × lon; predictions: model × lat × lon.
result = mp.compare_spatial(
    observations, predictions,
    row="model",
    projection=ccrs.LambertConformal(),
    extent=(-125, -65, 24, 51),
    vmin=0, vmax=60, bias_limit=8,
    cmap="viridis", bias_cmap="RdBu_r",
    rasterized=True,
)
result.save("model-evaluation.pdf")

    The runnable example uses synthetic surface ozone and a missing observation region. It needs no scientific data download; Cartopy caches the coastline on first use.

    Pairing and interpretation¶

    Inputs are xarray DataArrays. Select Dataset variables explicitly. Field dimension names, sizes, index labels, and spatial coordinates must match exactly. For curvilinear grids, the 2D longitude and latitude coordinates must also match. Where dimensions lack explicit index labels, they pair by position; the spatial coordinates must still match. Supply explicit period/model labels to make those comparisons unambiguous. Only a model-only row dimension broadcasts static observations intentionally. Use kind="scatter" for collocated station pairs on a shared sample dimension.

    Model output and station observations must be collocated before calling this function. Regrid/interpolate explicitly, choose a scientifically justified method, and align averaging windows and vertical levels. This function does not infer representativeness, collocation, unit conversion, or statistical significance.

    Both inputs must have the same units attribute, or both must omit it. Supplying units on only one input raises an error. Unit strings are compared literally: convert equivalent units and normalize their labels beforehand. data_crs applies to both inputs; projected coordinates require an explicit CRS.

    Non-finite values remain masked. A bias is shown only where both inputs are finite. The observation/model panels retain their individual valid values, even where a pair is missing. The returned bias, paired, and paired_counts expose those choices as xarray objects; counts are per row and have dimensionless units. Differences are calculated as model − observations, never the reverse.

    Scales and performance¶

    vmin and vmax set the common observation/model bounds. bias_limit=8 sets bias bounds to −8 and +8. Without limits, the common bounds cover finite values from both inputs and bias limits use the largest absolute finite paired difference across all rows. All-zero bias uses ±1 to retain a valid zero-centered scale.

    A custom concentration norm is supported. For bias, a custom bias_norm must be a TwoSlopeNorm centered on zero; do not combine it with bias_limit. Use cbar_kwargs for shared colorbar options and bias_cbar_kwargs to override bias-specific options. Set colorbar=False to omit both bars.

    Automatic bounds are reduced in one shared Dask compute graph. Explicit bounds skip those reductions. By default, materialize="row" evaluates the three fields in one shared graph per row, avoiding repeated source work without persisting an entire cube. materialize="panel" evaluates panels independently for comparison or different memory tradeoffs. Temporary arrays and Matplotlib artists still consume memory; reducing the number of tasks does not guarantee lower peak RSS.

    SpatialComparisonPlot(...).plot() offers the same workflow with delayed rendering. Construction preserves lazy field values and checks coordinates; validation may evaluate lazy coordinate arrays. The object can be rendered once; create a new object for another configuration.

    print(result.paired_counts.compute())
# Inspect bias directly with xarray:
print(result.bias.mean().compute())

    Do not use unweighted spatial means for quantitative conclusions when grid-cell areas or sampling weights differ. Aggregation and weighting remain explicit analysis steps.

    class SpatialComparisonPlot(BasePlot):
    """Observation, model and model-minus-observation panels, optionally by row.

    Inputs must be xarray DataArrays with the same dimension labels and spatial
    coordinates, already in the same units and CRS. A model-only ``row``
    dimension intentionally repeats static observations for each model/period.
    All other broadcasting and implicit regridding are rejected. Initialization
    preserves lazy field values; rendering resolves scales and computes panels.
    """

    def __init__(
        self,
        observations,
        model,
        *,
        row=None,
        kind="pcolormesh",
        x=None,
        y=None,
        projection=None,
        data_crs=None,
        extent_crs=None,
        size=3,
        aspect=1.25,
        style="wiley",
        **kwargs,
    ):
        if not isinstance(observations, xr.DataArray) or not isinstance(
            model, xr.DataArray
        ):
            raise TypeError(
                "Comparison inputs must be xarray DataArrays; select Dataset variables explicitly."
            )
        if kind not in {"pcolormesh", "imshow", "contourf", "scatter"}:
            raise ValueError("kind must be pcolormesh, imshow, contourf, or scatter.")
        self.x, self.y = identify_coords(model, x, y)
        self.observations, self.model = _paired_fields(
            observations,
            model,
            row=row,
            x=self.x,
            y=self.y,
        )
        validate_data_crs(model, self.x, self.y, data_crs)
        validate_data_crs(observations, self.x, self.y, data_crs)
        self.row, self.kind = row, kind
        field_dims = [dim for dim in model.dims if dim != row]
        expected = 1 if kind == "scatter" else 2
        if len(field_dims) != expected:
            raise ValueError(
                f"{kind} requires {expected} field dimensions; select extra dimensions or specify row."
            )
        self.paired = np.isfinite(self.model) & np.isfinite(self.observations)
        self.bias = (self.model - self.observations).where(self.paired)
        self.bias.name = "bias"
        self.bias.attrs = {"long_name": "Model − observations"}
        if model.attrs.get("units"):
            self.bias.attrs["units"] = model.attrs["units"]
        self.paired_counts = self.paired.sum(dim=field_dims)
        self.paired_counts.attrs = {
            "long_name": "Finite observation/model pairs",
            "units": "1",
        }
        self.data_crs = data_crs or ccrs.PlateCarree()
        self.extent_crs = extent_crs or ccrs.PlateCarree()
        self.render_options = kwargs
        self.plotters, self.mappables = [], []
        rows = model.sizes[row] if row else 1
        if rows == 0:
            raise ValueError("The comparison needs at least one row.")
        fig, axes = plt.subplots(
            rows,
            3,
            squeeze=False,
            figsize=(3 * size * aspect, rows * size),
            subplot_kw={"projection": projection or ccrs.PlateCarree()},
            layout="constrained",
        )
        super().__init__(fig=fig, ax=axes[0, 0], style=style)
        self.axes = axes

    def plot(
        self,
        *,
        vmin=None,
        vmax=None,
        norm=None,
        bias_limit=None,
        bias_norm=None,
        cmap="viridis",
        bias_cmap="RdBu_r",
        colorbar=True,
        cbar_kwargs=None,
        bias_cbar_kwargs=None,
        panel_labels=True,
        materialize="row",
        **kwargs,
    ):
        """Render with a common concentration scale and a zero-centered bias scale.

        Explicit vmin/vmax and bias_limit avoid global scale reductions. With
        automatic limits, all required scalar reductions share one Dask compute
        call. ``bias_norm`` must be a TwoSlopeNorm centered on zero; explicit
        ``bias_limit`` uses symmetric bounds. Empty panels retain masked values.
        """
        if self.mappables:
            raise RuntimeError(
                "This comparison has already been rendered; create a new plot to render again."
            )
        options = {**self.render_options, **kwargs}
        # Accept rendering configuration through the convenience constructor too.
        vmin, vmax = options.pop("vmin", vmin), options.pop("vmax", vmax)
        norm = options.pop("norm", norm)
        bias_limit = options.pop("bias_limit", bias_limit)
        bias_norm = options.pop("bias_norm", bias_norm)
        cmap, bias_cmap = options.pop("cmap", cmap), options.pop("bias_cmap", bias_cmap)
        colorbar = options.pop("colorbar", colorbar)
        cbar_kwargs = options.pop("cbar_kwargs", cbar_kwargs) or {}
        bias_cbar_kwargs = options.pop("bias_cbar_kwargs", bias_cbar_kwargs) or {}
        panel_labels = options.pop("panel_labels", panel_labels)
        materialize = options.pop("materialize", materialize)
        if materialize not in {"row", "panel"}:
            raise ValueError("materialize must be row or panel.")
        self.field_norm, self.bias_norm = _comparison_norms(
            self.observations,
            self.model,
            self.bias,
            vmin=vmin,
            vmax=vmax,
            norm=norm,
            bias_limit=bias_limit,
            bias_norm=bias_norm,
        )
        renderers = {
            "pcolormesh": SpatialMeshPlot,
            "imshow": SpatialImshowPlot,
            "contourf": SpatialContourPlot,
            "scatter": SpatialTrack,
        }
        feature_keys = {
            "extent",
            "coastlines",
            "states",
            "countries",
            "borders",
            "gridlines",
            "resolution",
            "natural_earth",
            "ocean",
            "land",
            "lakes",
            "rivers",
        }
        features = {
            key: options.pop(key) for key in list(options) if key in feature_keys
        }
        features.setdefault("coastlines", True)
        bias_levels = options.pop("bias_levels", None)
        for i in range(self.axes.shape[0]):
            fields = [
                data.isel({self.row: i}) if self.row and self.row in data.dims else data
                for data in (self.observations, self.model, self.bias)
            ]
            fields = [data.where(np.isfinite(data)) for data in fields]
            if materialize == "row" and any(data.chunks is not None for data in fields):
                # Shared Dask dependencies are evaluated once per three-panel row.
                # This bounds temporary data to a row rather than persisting the cube.
                fields = dask.compute(*fields)
            for j, (subset, title) in enumerate(
                zip(fields, ("Observations", "Model", "Model − observations"))
            ):
                selected_norm = self.bias_norm if j == 2 else self.field_norm
                panel_options = dict(options)
                if self.kind == "contourf":
                    levels = (
                        bias_levels if j == 2 else panel_options.pop("levels", None)
                    )
                    if levels is None or np.isscalar(levels):
                        levels = np.linspace(
                            selected_norm.vmin,
                            selected_norm.vmax,
                            int(levels) if levels is not None else 11,
                        )
                    panel_options["levels"] = levels
                plotter = renderers[self.kind](
                    subset,
                    ax=self.axes[i, j],
                    data_crs=self.data_crs,
                    extent_crs=self.extent_crs,
                    lon_coord=self.x,
                    lat_coord=self.y,
                    style=self._style,
                    **features,
                )
                plotter.plot(
                    norm=selected_norm,
                    cmap=bias_cmap if j == 2 else cmap,
                    add_colorbar=False,
                    **panel_options,
                )
                self.plotters.append(plotter)
                self.mappables.append(plotter.mappable)
                ax = self.axes[i, j]
                if self.row:
                    title = f"{self.row} = {self.model[self.row].values[i]}\n{title}"
                ax.set_title(title)
                if panel_labels:
                    from ..api import _panel_letter

                    ax.text(
                        0.02,
                        0.98,
                        f"({_panel_letter(i * 3 + j)})",
                        transform=ax.transAxes,
                        va="top",
                        fontweight="bold",
                        bbox={"facecolor": "white", "alpha": 0.8, "edgecolor": "none"},
                    )
                if hasattr(plotter, "gridliner"):
                    grid = plotter.gridliner
                    if any(
                        (
                            grid.left_labels,
                            grid.right_labels,
                            grid.top_labels,
                            grid.bottom_labels,
                        )
                    ):
                        grid.top_labels = grid.right_labels = False
                        grid.left_labels = j == 0
                        grid.bottom_labels = i == self.axes.shape[0] - 1
        self.mappable = self.mappables[0]
        if colorbar:
            common = {"orientation": "horizontal", "pad": 0.08, **cbar_kwargs}
            self.colorbars.append(
                self.fig.colorbar(
                    self.mappables[0],
                    ax=list(self.axes[:, :2].flat),
                    **{"label": variable_label(self.model), **common},
                )
            )
            self.colorbars.append(
                self.fig.colorbar(
                    self.mappables[2],
                    ax=list(self.axes[:, 2].flat),
                    **{
                        "label": variable_label(self.bias),
                        **common,
                        **bias_cbar_kwargs,
                    },
                )
            )
        return self
